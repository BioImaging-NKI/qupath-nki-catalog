# QuPath catalog NKI

This is a custom QuPath catalog maintained by [@BioImaging-NKI](https://github.com/BioImaging-NKI) containing extensions for QuPath.

## Extensions in this catalog

This catalog includes the following extension:

### QuPath SlideScore extension
Using the extension you can access slides on your Slide Score server from QuPath directly, exchange annotations or TMA core positions with the server and more.
[See Video](https://www.youtube.com/watch?v=nzKReknqQHE)

## Installation

To use this catalog in QuPath:

1. Open QuPath
2. Go to **Extensions → Manage extensions**
3. Click **Manage extension catalogs**
4. Enter the catalog URL: `[https://github.com/ksugar/qupath-catalog-ksugar](https://github.com/BioImaging-NKI/qupath-nki-catalog)`
5. Browse and install the extensions you need (only one available at the moment)

## About QuPath catalogs

QuPath uses [catalogs](https://github.com/qupath/extension-catalog-model) to easily install, manage, and delete QuPath extensions. 

To create your own custom catalog, follow the instructions at https://github.com/qupath/extension-catalog-model.
